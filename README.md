# MovieApp 🎬
MovieApp is a native iOS application that allows users to discover movies by genre, explore movie details, watch trailers, and read reviews using data from The Movie Database (TMDB).

## ✨ Features
- Browse movie genres
- Discover movies by selected genre
- View movie details (overview, rating, genres, release year, production companies)
- Watch official movie trailers on YouTube
- Read movie reviews with pagination
- Infinite scrolling for movie lists

## 🛠️ Built With
- Swift
- SwiftUI
- Combine
- VIPER Architecture
- Alamofire
- SDWebImageSwiftUI
- TMDB API
